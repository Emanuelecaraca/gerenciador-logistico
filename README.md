## 📌 Sobre o projeto

O **Gerenciamento Logístico** é um sistema desenvolvido com objetivo de facilitar o gerenciamento de operações logísticas, centralizando informações e organizando os principais processos relacionados ao transporte de produtos e mercadorias, permitindo gerenciar transportadores, veículos, endereços, produtos, fretes e documentos em um único sistema.

## ⚙️ Funcionalidades

- **Login:** acesso ao sistema.
- **Painel inicial:** página principal de navegação com indicadores básicos.
- **Transportadores e veículos:** cadastro e gerenciamento de transportadores e veículos vinculados.
- **Produtos:** cadastro e gerenciamento de produtos.
- **Endereços:** cadastro e gerenciamento de endereços.
- **Fretes:** cadastro, consulta e gerenciamento de fretes.
- **Documentos:** gerenciamento de documentos relacionados aos registros.
- **Relatórios:** consulta e filtragem de informações dos fretes.
- **Impressão:** visualização e impressão de relatórios.

## 📂 Estrutura do projeto

O projeto está organizado em diretórios para facilitar a manutenção e separar as responsabilidades de cada parte do sistema.

## 🚀 Como executar o projeto

1. Instale o XAMPP.
2. Inicie o serviço Apache.
3. Copie a pasta do projeto para o diretório `xampp -> htdocs`.
4. Abra o navegador.
5. Acesse `http://localhost/gerenciador-logistico/login.html`.

## 💾 Armazenamento de dados

O sistema utiliza sessões PHP (`$_SESSION`) para armazenar e manipular temporariamente os dados durante a utilização.

Nesta versão, não há integração com banco de dados relacional (SQL).

## 🎯 Objetivo acadêmico

A atividade prática foi desenvolvida como parte da disciplina de **Fundamentos de Programação para Internet**, do curso de Tecnologia em Análise e Desenvolvimento de Sistemas, com o objetivo de colocar em prática os conhecimentos adquiridos ao longo das aulas, explorando lógica de programação, desenvolvimento web, organização de arquivos, manipulação de dados e criação de interfaces interativas.
